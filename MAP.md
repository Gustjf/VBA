### Repo plumbing

| Path | Type | Description |
|------|------|-------------|
| `.gitattributes` | config | Marks `*.bas` as `-text` so the VBA module keeps its Windows (CRLF) line endings through git. |
| `.gitignore` | config | Ignores the `.build/` aux-file folder and Python `__pycache__/` folders. |
| `.preview/source` | config | Symlink to `../output` so LaTeX Workshop's PDF viewer finds the PDF `build.sh` wrote under `output/`. |
| `.vscode/settings.json` | config | VSCodium/VS Code LaTeX Workshop settings: build on save via `build.sh`, PDF opens in a tab. |
| `build.sh` | script | Compiles `source/<Topic>/x.tex` to `output/<Topic>/x.pdf` with latexmk (aux files in git-ignored `.build/`); no args builds every .tex, or pass file paths. |
| `CLAUDE.md` | instructions | Repo purpose and standing rules for Claude. |
| `LICENSE` | license | Repository license. |
| `MAP.md` | index | This file. |
